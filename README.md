# Employee Attrition Analysis & Prediction

Machine Learning project developed for a 6-hour Internal Data Science & AI/ML Hackathon.

## Problem

Predict whether an employee is likely to leave the organization based on employee, job, salary, experience and satisfaction-related information.

## Dataset

- 4,410 employee records
- 29 features
- Target: Attrition (Yes/No)

Dataset Source:
https://www.kaggle.com/datasets/anujachintyabiswas/attrition-rate-of-a-company

## Approach

- Data Cleaning
- Exploratory Data Analysis
- Feature Encoding
- Train-Test Split
- Logistic Regression
- Balanced Logistic Regression
- Decision Tree Classification

## Final Model

Balanced Decision Tree Classifier

- Accuracy: 75.62%
- Precision: 34.60%
- Recall: 57.75%
- F1-Score: 43.27%

## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib, Jupyter Notebook
